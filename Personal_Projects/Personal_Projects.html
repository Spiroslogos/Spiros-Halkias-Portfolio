Home Lab

I am running a Raspberry Pi 4 Model B 4GB RAM with a 128GB microSD as my first server. It has a variety of functions that are listed below, with the name of the application, and what I use it for:

Glances – Monitoring dashboard for Raspberry Pi. Shows temperature, RAM, processes, etc.

Vaultwarden – Password and private information manager

Pi-hole – Network-wide Ad-blocker with private domain name system

TigerVNC – Remote SSH desktop of my Raspberry Pi to access the headless hardware

WireGuard – VPN that allows access to my Raspberry Pi and the rest of these applications via any network around the world
